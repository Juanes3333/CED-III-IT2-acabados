\begin{abstract}
We study binary sentiment classification of Reddit comments drawn from GoEmotions. The project uses a balanced sample of 1,000 comments and compares a majority-class baseline with dense and recurrent neural classifiers. This report describes the dataset, preprocessing, and model design; subsequent sections document experimental results, comparisons, and theoretical implications.
\end{abstract}
