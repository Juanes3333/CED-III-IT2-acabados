\section{Dataset and Preprocessing}
The source is the filtered GoEmotions collection of English Reddit comments with emotion identifiers \cite{demszky2020goemotions}. The preprocessing pipeline loads the original training, development, and test TSV files and maps each emotion to a positive, negative, ambiguous, or neutral group. A comment receives a single group only when all its annotated emotions belong to that group; comments spanning groups are labeled mixed. Only purely positive and purely negative comments are retained.

Before sampling, duplicate texts are detected after lowercasing and whitespace normalization. All copies of a text are removed when conflicting sentiment labels are present; otherwise only one copy is kept. With random seed 1234, the pipeline samples 500 comments per class and performs a stratified 80/20 split: 800 training examples and 200 held-out test examples, balanced in each partition.

For model inputs, text is lowercased, masked \texttt{[NAME]} and \texttt{[RELIGION]} placeholders are removed, negative contractions are expanded, and punctuation is stripped. Common stopwords are removed while sentiment-bearing negations such as \texttt{not} and \texttt{never} are preserved. The dense model learns TF--IDF features from training data. The recurrent models use a Keras \texttt{TextVectorization} layer adapted only on training text, producing fixed-length integer sequences. Keeping feature fitting within the training partition prevents test-set vocabulary leakage.
